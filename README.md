# 📚 台灣中小學試題句子難度檢測系統

這是一個基於 Streamlit 與 spaCy 自然語言處理 (NLP) 技術開發的台灣中小學試題難度自動檢測與分析工具。

## ✨ 系統功能

1. **✍️ 單題檢測與複句分析**
   - 自動運算試題總字數、詞數、名詞/動詞出現比例。
   - 計算 **MDD (Mean Dependency Distance - 平均依存距離)**，衡量句法結構複雜度。
   - **複句句式自動判斷**：識別台灣國小常見的因果、轉折、假設、條件與並列等複句句式。
   - 預估題目適用年級（低年級 1-2、中年級 3-4、高年級 5-6）。

2. **📂 批次題庫上傳檢測**
   - 支援上傳 `.csv` 或 `.xlsx` 格式的現有題庫檔案。
   - 自動捕捉名為「題目」或「question」的欄位並進行全表逐題批次檢測。
   - 支援一鍵下載分析完成的繁體中文 CSV 報告（內建防亂碼 `utf-8-sig` 編碼）。
